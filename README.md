# Mintly Dental

Single-page site for a dental clinic: aligner hero, about + gallery, services, dentist carousel, online booking with a live open/closed status, illustrated map and footer.

```bash
npm install
npm run dev            # local dev server
npm run build          # production build in dist/
npm run render-stills  # re-render the 3D aligner/tooth/tool stills in public/3d
```

Pushes to `main` deploy to GitHub Pages via `.github/workflows/deploy.yml`.

Photos are free-licence Unsplash images (ids in `photo-ids.txt`). Address, phone, email, names and stats are placeholders.
